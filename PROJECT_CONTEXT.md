# PROJEKT-KONTEXT:  ROBERT THOMAS RAG-CHATBOT

## 🎯 ZIEL
Ein KI-Chatbot, der Fragen über die Firma Robert Thomas beantwortet. 

## 🏢 FIRMENWISSEN (KRITISCH)
- **ROTHO** = Industrieanlagen (Ziegel- & Betontrocknung) → rotho.de
- **THOMAS** = Haushalt (Staubsauger, AQUA-BOX) → robert-thomas.de
- ⚠️ **THOMAS MAGNETE** (Herdorf) = ANDERE FIRMA, NICHT VERWANDT! 

## 🛠️ TECH STACK
- Framework: Next.js 15 (App Router)
- Template: Vercel Chat SDK (vercel/ai-chatbot)
- Database: Supabase PostgreSQL + pgvector
- Embeddings: OpenAI text-embedding-3-small
- LLM: Claude Sonnet 4 via Anthropic API
- Scraping: Firecrawl API
- Hosting: Vercel
